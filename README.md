# 🛍️ Customer Shopping Behaviour Analysis

End-to-end data analytics project: **Python (pandas) → PostgreSQL → Dashboard**.
It analyses 3,900 customer transactions to understand what customers buy, how much they spend, and how discounts, shipping, payment methods and subscriptions affect purchasing.

## 📊 Dashboard

![Customer Shopping Behaviour Dashboard](Dashboard-Png/customer_behvaior_ds.png)

## 🎯 Project Objective
Turn raw retail transaction data into clear business insights about revenue drivers, customer segments and purchasing patterns.

## 🔄 Workflow

| Step | Tool | What was done |
|---|---|---|
| 1. Data preprocessing | Python, pandas, Jupyter | Cleaned and enriched the data |
| 2. Data storage | PostgreSQL, SQLAlchemy | Loaded the cleaned data into a `customer` table |
| 3. SQL analysis | PostgreSQL | Answered 10 business questions |
| 4. Visualisation | BI dashboard | KPIs and charts with interactive filters |

## 🧹 Data Preprocessing
- Inspected the data: 3,900 rows × 18 columns
- Filled 37 missing `Review Rating` values with the **median rating of each category**
- Renamed columns to snake_case (e.g. `Purchase Amount (USD)` → `purchase_amount`)
- Created **`age_group`** (4 quartile-based groups: Young Adult, Adult, Middle-Aged, Senior)
- Created **`purchase_frequency_days`** by converting text frequency (Weekly, Monthly, etc.) to days
- Dropped `promo_code_used` after confirming it is identical to `discount_applied`
- Loaded the final table (3,900 rows × 19 columns) into PostgreSQL

## 🗃️ SQL Analysis
The queries in the `PgSQL` folder answer these business questions:

1. What is the revenue generated by male and female customers?
2. Which customers used a discount but still spent more than the average purchase amount?
3. Which 5 products have the highest average review rating?
4. How does average spend compare between Standard and Express shipping?
5. Do subscribers spend more than non-subscribers?
6. Which 5 products have the highest percentage of discounted purchases?
7. How can customers be segmented into New, Returning and Loyal?
8. What are the top 3 products in each category?
9. Are repeat buyers more likely to be subscribers?
10. What is the revenue contribution of each age group?

**SQL concepts used:** `GROUP BY`, aggregate functions, subqueries, `CASE WHEN`, CTEs, window functions (`ROW_NUMBER() OVER (PARTITION BY ...)`).

## 💡 Key Insights
- **Clothing is the top category** (about 45% of revenue), followed by Accessories (about 32%). Footwear and Outerwear are much smaller.
- **Only 27% of customers are subscribers**, so converting more customers to subscriptions is a clear growth opportunity.
- **Top products earn similar revenue** (Blouse, Shirt, Dress, Pants, Jewelry), so sales are spread across many items instead of relying on one.
- **Payment methods are evenly used**, with Credit Card, PayPal, Cash and Debit Card each near 40K.
- **Average purchase is about 60** (range 20–100), so growth depends mostly on customer count and purchase frequency.

```bash

```
2. Install the libraries
```bash
   pip install pandas sqlalchemy psycopg2-binary jupyter
```
3. Open the notebook in `Jupyter-Notebook/` and run all cells. Update the database username, password and name to match your own PostgreSQL setup.
4. Run the queries from the `PgSQL/` folder on the `customer` table.
